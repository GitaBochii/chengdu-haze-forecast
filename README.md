# 成都雾霾消散时间预测

基于成都历史空气质量、气象数据与机器学习模型，估计污染过程距离稳定恢复还需要多少时间。项目提供展示页和操作页，可查看历史回测、输入污染物与气象数值、导入小时序列，并展示污染反弹案例与多模态研究结果。

## 本地运行

需要 Windows x64 和已安装的 **64 位 Python 3.11、3.12 或 3.13**，推荐 Python 3.12。未安装 Python 时，入口会给出 [官方下载页面](https://www.python.org/downloads/windows/)，不会自动安装或修改系统 Python。

从 GitHub 点击 **Code → Download ZIP**，完整解压后，在项目目录双击：

| 文件 | 用途 |
| --- | --- |
| **安装并启动网页.cmd** | 第一次使用：准备项目环境、安装依赖并打开网页 |
| **启动网页.cmd** | 日常启动：检查已有环境并打开网页，缺少依赖时自动补装 |
| **停止网页.cmd** | 结束这个项目的本地后台服务 |

首次安装需要联网，下载依赖可能需要几分钟。安装目录是项目自己的 `.venv`，包含 CPU 版 PyTorch，不需要显卡或管理员权限。安装失败时查看窗口提示，排除网络问题后重新双击即可；不要直接在 ZIP 压缩包里运行入口。

启动脚本会自动打开本地网页，并在 8510 至 8530 之间选择空闲端口。终端输出的 `Website` 地址是本次运行的实际地址。

- 展示页：`http://127.0.0.1:端口/`
- 操作页：`http://127.0.0.1:端口/workbench.html`

服务只监听本机。重复启动会复用这个项目已运行的服务，不会占用新的端口；不同下载副本的服务互不复用。关闭浏览器不会停止后台服务，需要停止时双击 `停止网页.cmd`。

### 多模态重新推理

一键安装已包含多模态重新推理所需的 CPU 版 PyTorch。多模态历史归档和对应融合预测头均可在操作页查看、运行。

重新推理使用已保存的污染物输入和气象空间特征，不会在打开网页时重新下载或运行完整 Prithvi 气象编码器。CPU 即可运行该历史案例预测头。

## 操作页功能

| 功能 | 输入 | 输出 |
| --- | --- | --- |
| 严格历史回测 | 选择历史日期与起点 | 已归档的预测时长、观测恢复时长及误差 |
| 手动输入 | 当前污染物、气象数值与时间 | 当前条件下的剩余消散时间估计 |
| 24 小时序列 | 连续小时 CSV | 使用历史变化信息的剩余时间估计与输入曲线 |
| 在线估算 | 外部服务提供的估算序列 | 序列预览与研究性时长估计 |
| 反弹与恢复 | 选择历史案例 | 未来 AQI 预测曲线、实际曲线与反弹情况 |
| 多模态研究 | 固定历史起点、模型与随机种子 | 污染序列基线、容量对照、气象空间融合结果及真实输入气象场 |

普通结果区中的 AQI、PM2.5、PM10 曲线是输入观测，不是 AFT 预测的未来浓度。反弹案例页另有 LightGBM 的未来浓度预测曲线。

## 模型分工

- **XGBoost AFT**：直接学习恢复时间，负责普通手动预测与小时序列预测。AFT 能利用区间标签及尚未观察到恢复的删失样本；剩余时间不是由历史曲线线性外推得到的。
- **LightGBM**：用于未来浓度与连续轨迹研究。网页反弹案例读取事先计算的未来 24 小时 AQI 预测，比较短暂达标与持续恢复，不在点击时重新训练模型。
- **Prithvi 气象编码器与污染物图网络**：气象编码器从 MERRA-2 多通道网格提取区域天气特征，与多站点污染物历史特征融合，由下游预测头估计恢复时间。该路线位于多模态研究区，不直接替代普通 AFT 模型。

恢复时间研究采用 AQI 不高于 100 并连续保持 6 小时的稳定窗口；窗口开始时刻与观察满 6 小时后的确认时刻不同。不同研究分支的目标、年份和预测上限以对应结果说明为准。

多模态网页案例为 2020 年的 25 个历史起点，展示值按 68 小时封顶；68 小时表示至少 68 小时，不表示精确恢复时刻。该页不代表全历史样本或实时预报性能。

## 文件导航

| 路径 | 内容 |
| --- | --- |
| `src/haze_forecast/` | 数据处理、特征构造、标签、模型与网页服务 |
| `project-showcase/` | 展示页、操作页、反弹案例与输入气象图 |
| `scripts/` | 启动、数据处理、训练与检验脚本 |
| `tests/` | 模型输入、恢复定义、服务和页面集成测试 |
| `experiments/` | 连续轨迹与多模态等研究源码及必要运行文件 |
| `data/processed/regional_air_models_full_history/` | 城市、站点小时数据和气象代理 |
| `artifacts/cnemc_2025_deployment_candidate/` | 普通网页使用的 AFT 模型与元数据 |
| `artifacts/strict_history_backtest/predictions.parquet` | 网页历史回测预测归档 |
| [DATA.md](DATA.md) | 数据格式、来源与使用说明 |

完整观测时间轴覆盖 2014 年 5 月 13 日至 2026 年 9 月 3 日。时间轴范围不等于每小时、每个变量都有有效观测，也不代表各模型使用了全部年份训练。

本项目用于历史研究与演示。在线输入属于模型估算而非监测站实测；离线再分析气象数据不等同于预测时刻可获得的实时天气。只加载本仓库或其他可信来源的模型文件，不要加载来源不明的 `joblib` 文件。

## 基础检验

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest tests/test_showcase_server.py tests/test_showcase_online.py tests/test_rebound_cases.py tests/test_rebound_integration.py
```

多模态重新推理还需要 PyTorch 及对应的固定模型、输入和完整性校验文件。数据的来源说明与第三方代码的许可证应随使用保留。
